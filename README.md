# AOSP-Music-Material-3
Based on Android Open Source Project, revamped the UI with a Material 3 look

Changelogs:
- New Audio player interface that fits to Material 3 design
- Wavy seek bar
- Dynamic colors

Currently in beta phase, some visuals and assets are existing in this build including Video Player, Media Picker etc. 
Based on AOSP music player 4.2.2 Jellybean Holo source code.
